\subsection{Dataset: HotpotQA}
% HotpotQA: Yang et al. 2018 — multi-hop reasoning over Wikipedia
% 1000 questions per mode, 9 modes = 9000 evaluated questions
% Why HotpotQA: multi-hop nature stresses retrieval; widely used RAG benchmark
% Cite: \cite{yang2018hotpotqa}

\subsection{Metrics}
% Token F1: token-level overlap between predicted and gold answer
% Exact Match (EM): binary — 1 iff prediction equals gold after normalisation
% ROUGE-L: longest common subsequence F-measure
% Faithfulness (RAGAS): fraction of answer claims supported by retrieved context
% Answer Relevance (RAGAS): cosine similarity of reverse-generated questions
% Context Recall (RAGAS): fraction of gold answer attributable to retrieved context
% Latency: mean, median, p95 (wall clock ms per query)
