# thesis-latex

LaTeX source for the Master's thesis.

## Compile locally
```
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Overleaf sync
1. In Overleaf: New Project → Upload Project → zip this folder.
2. Set compiler to **pdfLaTeX** and main document to `main.tex`.
3. To keep in sync: git push → download zip from GitHub → re-upload, or use
   Overleaf GitHub integration (Settings → GitHub Sync).

## File structure
```
main.tex                  ← master file, title page metadata here
chapters/
  ch1_introduction.tex
  ch2_background.tex
  ch3_rare_rag.tex
  ch4_system_design.tex
  ch5_implementation.tex
  ch6_evaluation.tex
  ch7_conclusions.tex
figures/                  ← PDF/PNG figures generated by scripts/thesis_figures.py
bibliography.bib
aghdpl.cls                ← AGH document class (do not modify)
agh.jpg / agh.eps         ← AGH logo
```

## Generating figures
```
cd scripts
python thesis_figures.py   # generates all seaborn figures to thesis-latex/figures/
```
